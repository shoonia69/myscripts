# Ansible multiselect playbook

Запуск:

```bash
cd /root/git/myscripts/ansible-multiselect
./run.sh
```

Скрипт спросит IP конечных хостов, SSH-пользователя и пункты меню. Хосты можно вводить через пробел или запятую:

```text
192.168.1.10 192.168.1.11
```

или:

```text
192.168.1.10,192.168.1.11
```

Файл `hosts` редактировать не нужно: временный inventory создается автоматически.

Проверка SSH-отпечатка отключена через:

```bash
ANSIBLE_HOST_KEY_CHECKING=False
-o StrictHostKeyChecking=no
```

По умолчанию подключение выполняется пользователем `root`, но при запуске можно указать другого пользователя. Так как задачи требуют прав администратора, для пользователя не `root` используется Ansible `become`; если sudo требует пароль, ответьте `y` на вопрос про sudo/become.

Если локального SSH-ключа нет, `run.sh` создаст его. Если ключ еще не добавлен на целевой сервер, `run.sh` сам запустит `ssh-copy-id` для каждого указанного хоста; при парольной авторизации сервер может один раз попросить пароль выбранного SSH-пользователя.
